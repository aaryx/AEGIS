## 1. Classification Categories

Every requirement and validation item is classified into one of the following five verification tiers:
1. **Verified by Actual Runtime Execution:** Executed directly against active runtime processes or system resources.
2. **Verified by Automated Test:** Executed deterministically through automated test runners (Pytest, Vitest, etc.).
3. **Verified by Static Inspection:** Validated via automated linters, AST security scanners, type checkers, and source auditing.
4. **Simulated or Mock-Based:** Validated using synthetic fixtures, in-memory drivers, or subprocess mocks.
5. **Not Run / Blocked:** Intentionally omitted due to safety, infrastructure unavailability, or resource constraints.
